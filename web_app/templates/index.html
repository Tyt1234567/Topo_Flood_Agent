Optional: population / exposure data

Flood risk can optionally be weighted by how many people or structures are near each hotspot. There's no live online source for this, so if you have a CSV (header x,y,value) or shapefile (.zip with POINT geometry + a value field), attach it here. If not, this factor is simply left out -- every other part of the analysis still runs normally.
